# 🚦 Traffic Analysis 2.0 – YOLOv8 Multi-Class Detection Dataset

This dataset was created and annotated by **Hamza Ali Khan** using Roboflow for training advanced object detection models such as YOLOv8.

---

## 📊 Dataset Overview

- **Total Images:** 997  
- **Format:** YOLOv8 (Oriented Object Detection)  
- **Image Size:** 640 × 640  

---

## 🚗 Classes

- Bike  
- Bus  
- Car  
- Cart  
- Person  
- Rickshaw  
- Suzuki  
- Truck  
- Van  

---

## ⚙️ Preprocessing

- Images resized to **640 × 640** (fit within)

---

## 🔁 Augmentations

- Gaussian blur (0–1.2 pixels)  
- Salt & pepper noise (0.1% of pixels)  

---

## 🧠 Use Cases

- Traffic analysis systems  
- Smart city applications  
- Autonomous driving research  
- Object detection model training  

---

## 🛠 Tools Used

- Roboflow (annotation & dataset management)  
- YOLOv8 (model training)
